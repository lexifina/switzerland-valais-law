# Art. 4 Eaux superficielles
1 Les eaux superficielles, telles que les lacs, les étangs, les fleuves, les rivières, les torrents et les courants d'eau dans un chenal naturel ou artificiel, comprennent le lit, les berges, les rives, les digues ainsi que les contre-canaux.
2 Le département chargé des cours d'eau (ci-après: département) définit les eaux publiques superficielles, en dresse un inventaire ainsi qu'un plan cartographique.
3 Selon l'intérêt public qu'elles présentent, ces eaux sont délimitées en tant que fonds indépendants. Pour les eaux superficielles non délimitées, la ligne apparente de leur action régulière est prise généralement comme limite.
