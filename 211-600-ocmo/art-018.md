# Art. 18 Documents de mutation
1 Le procès-verbal de mutation contient les éléments suivants:
a) la page de titre;
b) le plan de mutation avec les surfaces partielles;
c) le tableau de mutation;
d) la description des biens-fonds selon l'ancien état;
e) la description des biens-fonds selon le nouvel état.
2 Le dossier technique à l'intention du canton comportera, en sus du procès-verbal de mutation, les levés de terrain ainsi que les calculs y relatifs.
