# Art. 12 Documents de mutation
1 Le procès-verbal de mutation contient les éléments suivants:
a) la page titre;
b) le plan de mutation avec les surfaces partielles;
c) le tableau de mutation;
d) la description des biensfonds de l'ancien état avec indication des propriétaires;
e) la description des biensfonds du nouvel état.
2 Lors d'une expropriation, le procès-verbal de mutation contient les éléments suivants:
a) la page titre;
b) le plan de mutation avec les surfaces partielles;
c) le tableau de mutation;
d) la description des biensfonds de l'ancien état avec indication des propriétaires;
e) la description des biensfonds du nouvel état avec indication des propriétaires.
3 Le dossier technique à l'intention du canton comportera, en sus du procès-verbal de mutation, les levés de terrain ainsi que les calculs y relatifs.
