# Art. 5 Confidentialité des données
1 Les utilisateurs doivent traiter les données de la BDR-EE de manière confidentielle, de surcroît dans le respect du secret de fonction, pour autant qu’elles ne soient pas publiques par le biais d’une base de données source.
