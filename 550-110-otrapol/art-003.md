# Art. 3 Traitement de base
1 Le traitement de base est fixé dans le cadre de l'échelle des traitements de l'Administration cantonale.
2 Si le marché du travail le demande, et la situation financière économique du canton le permet, le Conseil d'Etat peut augmenter d'une manière adéquate le traitement de base jusqu'à un maximum de cinq pour cent.
