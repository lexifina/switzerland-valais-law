# Art. 14 Dérogations à l'émolument proportionnel
1 Lorsqu'une promesse de vente ou un droit d'emption a été conclu, l'émolument pour la vente est réduit de moitié, si c'est le même notaire qui instrumente les deux actes.
2 Si, dans un acte de vente, il est constitué une hypothèque légale, le notaire perçoit le droit proportionnel pour la vente et, en sus pour le montant garanti dans le gage immobilier, un émolument de 1‰.
3 Pour le cautionnement et la promesse de cautionner, l'émolument est de:
a) jusqu'à 10'000 francs 200 francs
b) au-delà 2‰ jusqu'à un émolument maximal de 1'000 francs
