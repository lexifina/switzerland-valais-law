# Art. 11 Répression des infractions
1 Le juge pénal ordinaire est compétent pour prononcer les arrêts prévus par le concordat. La procédure est réglée par le code de procédure pénale.
2 Le département est compétent pour prononcer les amendes prévues par le concordat. La procédure est réglée par les dispositions applicables aux prononcés pénaux administratifs.
