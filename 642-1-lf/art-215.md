# Art. 215 3. Code pénal
1 Les dispositions générales du Code pénal suisse sont applicables, sous réserve des prescriptions contraires de la présente loi.
2 L'article 49 du Code pénal suisse n'est applicable qu'aux peines privatives de liberté.
3 Les amendes prononcées en cas de contraventions ne peuvent être converties en arrêts.
