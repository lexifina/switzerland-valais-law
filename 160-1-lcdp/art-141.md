# Art. 141 Candidatures multiples
1 Les candidatures multiples sont interdites.
2 Le candidat dont le nom figure sur plus d'une liste dans le même district est biffé immédiatement de toutes les listes par le préfet du district.
3 Le candidat dont le nom figure sur une liste dans plusieurs districts est biffé immédiatement de toutes les listes par le Conseil d'Etat.
